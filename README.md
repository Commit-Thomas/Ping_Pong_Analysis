# Ping Pong Community Analytics

## What is this?
An early-stage data project exploring whether player progression, match competitiveness, and community engagement can be measured from ping pong match data — laying the groundwork for a future community app.

## The Problem
Recreational ping pong players have no structured way to track improvement, measure match quality, or feel part of a growing community beyond the game they just played.

## The Data
- **Original dataset** — 7,851 real tournament matches from June–July 2022, 565 players
- **Synthetic dataset** — 50,000 additional rows generated to simulate 8 months of community growth, 300 new players introduced over time, player progression modelled using Elo ratings
- **Feature dataset** — engineered fields added on top: Elo ratings, win rates, win streaks, and match type classifications

## Current Status
Early exploration phase. Data pipeline and feature engineering complete. Prediction model and app design are next steps.
